# OpenPlayer

A free, open-source, offline music player for Android, built with Expo and React Native.
No ads, no analytics, no accounts.

> **Status: alpha (v0.1.0).** The core loop works: scan your music, browse by folder and play it.
> Many features in the long-term plan are not built yet; see [What works today](#what-works-today)
> for an honest list.

## What works today

| Area | Status |
|---|---|
| Scan the device's audio library (MediaStore) | Working. Adds new files and removes deleted ones |
| Browse by folder and play songs | Working |
| Player: play/pause, next/previous, seek position display | Working |
| Repeat (off / one / all) and shuffle | Working |
| Queue position saved and restored per queue | Working in the playback service; queue management UI is not built |
| Sleep timer (time or song count) | Working in the playback service; no UI yet |
| Light/dark theme (follows the system) | Working |
| Artists, albums, genres | **Not yet**: tags are not read, so only file names are shown |
| Playlists, tag editor, lyrics | **Not yet** (database tables exist, no UI) |
| Equalizer, pitch control | **Not yet**: settings are stored but not applied to the audio |
| Gapless playback | **Not yet** |
| Lock-screen/notification controls, headset buttons, Android Auto, widgets | **Not yet**: needs a native media session |
| Backup & restore | **Not yet** |

## Install

Download the latest APK from the [Releases page](https://github.com/openplayer-project/openplayer/releases),
verify it against `SHA256SUMS.txt`, and install it (you may need to allow installs from your browser or
file manager). Android 7.0 (API 24) or newer.

Alpha builds are published as GitHub pre-releases. If a release says "debugkey" in the file name it was
signed with a debug key and is for testing only.

## Privacy

OpenPlayer contains no analytics, advertising or networking code, and your library never leaves your device.
See the [privacy policy](docs/privacy-policy.md).

| Permission | Why |
|---|---|
| `READ_MEDIA_AUDIO` (Android 13+), `READ_EXTERNAL_STORAGE` (Android 12 and below) | Find and play your music |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `WAKE_LOCK` | Keep playing with the screen off |

## Build from source

Requirements: Node.js 18+ (20 recommended), JDK 17, Android SDK 34.

```bash
git clone https://github.com/openplayer-project/openplayer.git
cd openplayer
npm install
npm run typecheck && npm run lint && npm test

# Run on a device or emulator (needs a development build; Expo Go cannot load the native modules used here)
npx expo prebuild --platform android
npx expo run:android
```

The `android/` folder is generated by `expo prebuild` from `app.config.ts` and is not committed.

## Project structure

```
app/            Expo Router routes (tabs + folder detail)
src/
  screens/      Screen components
  services/     DatabaseService, LibraryService (scan), PlaybackService
  hooks/        Hooks bridging services and the store
  store/        Zustand state
  db/           Drizzle schema and versioned SQL migrations
  theme/        Theme tokens
  utils/        Errors, validation, storage
experimental/   Unused UI components kept for reference (not built)
docs/           Privacy policy, release guide
```

Database changes: add a new entry to `MIGRATIONS` in `src/db/migrations.ts` (never edit a shipped one) and
update `src/db/schema.ts` to match.
